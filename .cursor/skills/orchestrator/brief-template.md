# Brief template

Save as `Orchestrator/briefs/YYYY-MM-DD-slug.md`. Append a short pointer in the target agent's `inbox.md`.

```markdown
# Brief: <short title>

- **Date:** YYYY-MM-DD
- **From:** Xiao (via Orchestrator)
- **To:** <Agent>
- **Priority:** P0 | P1 | P2
- **Related files:** <paths>

## Verbatim
> Xiao's words, unchanged.

## Intent
One paragraph: what success looks like.

## Scope
- In:
- Out:

## Constraints
Decisions and project rules that apply (cite `decisions.md` dates if relevant).

## Ask
Concrete deliverable (file paths, pages, or questions to answer).

## Done when
Checklist the agent can tick.
```
